About This Portal

Project Overview

TheosophicalAlchemyDB is a comprehensive digital humanities resource documenting the history and significance of Rosicrucian and spiritual alchemy traditions from the 16th to 19th centuries.

Scholarly Framework

This portal integrates scholarship from key historians including Frances Yates, Joscelyn Godwin, Tobias Churton, Urszula Szulakowska, and Mike Zuber's definitive work on spiritual alchemy from Jacob Böhme to Mary Anne Atwood. The revisionist historiography of Lawrence Principe and William Newman on laboratory alchemy grounds all entries in current scholarship.

Data Sources

The portal covers 100 historical figures, 67 concepts, 83 scholarly texts, and 135 alchemical emblems, with 63 chronological events and 15 geographic learning centers fully documented.

Technology

Built with vanilla JavaScript, Leaflet.js for mapping, and a comprehensive JSON database supporting both historical scholarship and interactive exploration. Deployed via GitHub Pages.
