API Access

For developers: All catalog JSONs are directly accessible via HTTP GET. Use these endpoints in your applications.

Direct JSON Endpoints

Base URL: /prototype/

/gallery_catalog.json /emblem_catalog.json /concept_index.json /emblem_text_links.json /text_chapters.json

Example: fetch('/prototype/gallery_catalog.json').then(r => r.json())

CORS Policy

All endpoints are CORS-enabled for safe cross-origin requests. Use in browser applications, dashboards, and external analysis tools.

Research Workflows

Suggested data exports for common research questions:

Motif Genealogy

Download gallery_catalog.json + concept_index.json. Extract entries tagged with a motif (lion, serpent, dragon). Trace occurrence across corpora and time.

Textual Context

Download text_chapters.json + emblem_text_links.json. For a given emblem, pull all chapters mentioning its motifs. Compare linguistic treatment.

Concept Networks

Download concept_index.json. Analyze co-occurrence graph. Which concepts cluster? How do relationships differ by corpus?

Corpus Comparison

Download gallery_catalog.json. Group by project_key. Compare distribution of motifs, categories, and confidence scores across sources.
